# Sentence structures to break

Adapted from stop-slop by Hardik Pandya (MIT), https://github.com/hardikpandya/stop-slop

Vocabulary tells are easy to catch and easy to swap out. These are the ones that
survive a find-and-replace, because the shape of the sentence is the tell, not
any word in it.

## Binary contrasts

Telegraphed reversals. The setup exists only to make the payoff feel earned.

| Pattern | Fix |
|---------|-----|
| "Not because X. Because Y." | State Y. |
| "X isn't the problem. Y is." | "The problem is Y." |
| "The answer isn't X. It's Y." | "The answer is Y." |
| "It feels like X. It's actually Y." | State Y. |
| "The question isn't X. It's Y." | Ask Y, or answer it. |
| "It's not X, it's Y." | State Y. |
| "stops being X and starts being Y" | Name what changed. |
| "not just X, but Y" | State Y. |
| "is about X but not Y" | State X. |

Drop the negation entirely. If the contrast carries real information, the reader
needs to know why someone would have believed X, which takes a sentence, not a
clause.

## Negative listing

"Not a framework. Not a library. A way of thinking." A striptease through
negation. State the last item and cut the runway.

## Dramatic fragmentation

| Pattern | Problem |
|---------|---------|
| "[Noun]. That's it. That's the whole idea." | Performative simplicity |
| "X. And Y. And Z." | Staccato drama |
| "This changes something. Everything." | Manufactured revelation |

Write complete sentences. A fragment lands when it is rare.

## Rhetorical setups

These announce insight instead of delivering it: "What if we reframed this?",
"Here's what I mean:", "Think about it:", "And that's okay." Make the point and
let the reader draw the conclusion.

## False agency

Inanimate things given human verbs. The model reaches for this because it avoids
naming an actor it doesn't know.

| Pattern | Why it's wrong |
|---------|----------------|
| "a complaint becomes a fix" | The complaint did nothing. Someone fixed it. |
| "the decision emerges" | Someone decided. |
| "the culture shifts" | People changed behavior. |
| "the data tells us" | Someone read it and drew a conclusion. |
| "the market rewards" | Buyers paid for something. |
| "the conversation moves toward" | Someone steered it. |

Name the human. If no specific person fits, "you" puts the reader in the seat.

## Narrator from a distance

"Nobody designed this." "People tend to." "This is why." Lecturer voice floating
above the scene. Put the reader in the room instead: "You don't sit down one day
and decide to."

## Vague declaratives

Sentences that assert importance without naming the thing: "The reasons are
structural." "The implications are significant." "The stakes are high." "This is
the deepest problem." Replace with the specific reason, implication, or stake,
or cut.

## Telling instead of showing

"This is genuinely hard." "This is what leadership actually looks like." If it
were hard, the detail would show it. Give the detail.

## Meta-commentary

The piece narrating its own structure: "The rest of this essay explains", "Let
me walk you through", "In this section we'll", "As we'll see", "Plot twist:",
"Hint:". Delete all of it and let the piece move.

## Throat-clearing openers

Announcements before the point. Cut and state the point.

"Here's the thing:", "Here's what/why/how [X]", "The truth is,", "The
uncomfortable truth is", "It turns out", "The real question is", "Let me be
clear", "I'm going to be honest", "Can we talk about", "At its core", "In
today's [X]", "In a world where", "When it comes to", "At the end of the day",
"The reality is".

## Emphasis crutches

Add no meaning. Delete on sight.

"Full stop.", "Period.", "Let that sink in.", "Make no mistake", "This matters
because", "Here's why that matters", "It's worth noting".

## Sentence starters

| Pattern | Fix |
|---------|-----|
| Opening on What, When, Where, Which, Who, Why, How | Lead with the subject. "What makes this hard is" becomes "The constraint is", then name it. |
| Paragraph opening on "So" | Start with content. |
| "Look," | Cut. |

## Lazy extremes

"Every", "always", "never", "everyone", "nobody". False authority doing vague
work. Use the actual scope: "every team I asked" or "three of the five".

## Business jargon

| Avoid | Use |
|-------|-----|
| navigate (challenges) | handle, address |
| unpack | explain, examine |
| lean into | accept, commit to |
| deep dive | analysis |
| double down | commit, increase |
| circle back | return to |
| take a step back | reconsider |
| moving forward | next, from now |
| on the same page | agreed |
| game-changer | name the change |
